# SwiftUI-Instruments-Demo

A SwiftUI demo app showcasing **performance profiling and optimization techniques** using Xcode Instruments.  
This project demonstrates how to identify and fix performance bottlenecks in SwiftUI apps, including memory usage, network calls, dropped frames, and unnecessary view recompositions.

---

## 🚀 Features
- **Lazy Stacks** → Efficient rendering of large datasets with `LazyVStack`.  
- **Image Optimization** → Async image loading with caching to reduce memory and network overhead.  
- **Instruments Profiling** → Setup for Memory, Network, Core Animation, Time Profiler, and SwiftUI instruments.  

---

## 📊 Instruments Used
- **Memory Instrument** → Detect leaks and prove caching prevents repeated allocations.  
- **Network Instrument** → Show how `URLCache` reduces redundant API calls.  
- **Core Animation Instrument** → Monitor dropped frames and ensure smooth scrolling.  
- **SwiftUI Instrument** → Detect unnecessary view recompositions.  
- **Time Profiler** → Measure CPU usage and identify slow functions.
